# Tic Tac Toe Game

A two-player Tic Tac Toe game built with vanilla JavaScript, HTML, and CSS.

> **Status: In progress.** The game is not finished yet.

## Progress

- [x] Project setup (HTML, CSS, JavaScript files)
- [x] Player factory function
- [x] Player name and X or O choice
- [x] Computer picks a random marker
- [ ] Game board (module pattern)
- [ ] Place markers on the board
- [ ] Check for a winner or a tie
- [ ] Show the board on the page (DOM)
- [ ] Restart button
- [ ] Styling

## How to Play (coming soon)

1. Open the game in your browser.
2. Type your name and choose X or O.
3. Take turns placing your marker on the board.
4. The first player with 3 in a row wins.

## Built With

- HTML
- CSS
- JavaScript (module pattern and factory functions)

## Run It Yourself

1. Clone the project:
   `git clone git@github.com:BlackCat13656/tic-tac-toe-game.git`
2. Open `index.html` in your browser.
